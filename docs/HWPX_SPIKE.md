## 포맷 요약

- **HWPX**는 ZIP 컨테이너 + XML(본문·스타일·헤더 등)로 구성된 개방형 문서 포맷입니다.
- 일반적인 구조:
  - `mimetype`
  - `Contents/header.xml`, `Contents/section0.xml`, …
  - `Contents/content.hpf` (매니페스트)
  - 미디어 리소스

## 파서 전략 (MVP)

| 선택 | 이유 |
|------|------|
| 표준 라이브러리 `zipfile` + `xml.etree.ElementTree` | 외부 상용 SDK 의존 최소화 |
| 네임스페이스 무시/로컬네임 매칭으로 텍스트 노드 수집 | 스키마 버전 편차 완충 |
| export: ZIP 복사 후 XML 텍스트 치환 | 완전 레이아웃 보존보다 문자열 제거 우선 |

## 라이선스

- HWPX **파일 포맷** 자체는 공개 명세 성격으로 다룸.
- 한컴 오피스 **SDK/엔진**은 사용하지 않음 → 엔진 라이선스 이슈 회피.
- 앱은 Apache-2.0, 의존성은 기존 THIRD_PARTY 고지 유지.
